# ZJ 还本付息协审规则

规则版本：V1.0。适用流程：还本付息申请表。适用规则：ZJ-R08。
来源：`input/资金/资金审阅规则.xlsx`；完整口径见 `docs/seeds/规则ZJ.md`。本文件为查阅副本，执行规则已内嵌于对应 SOP 节点指导。

## 审阅说明

规则按材料正文识别 B00–B04 来源，文件名仅供辅助。结论级别为风险、关注、通过。原表 D 列明确写「风险·拦截」时按风险判定，H 列原文作为口径依据保留；留空阈值不得自行补造。材料缺失导致不能核实时，记录关注（待补正）并说明未完成实质判定。每条结论保留 rule_id、实际材料与关键字段证据。

R08 仅在贷款人为外部金融机构时执行；否则不生成判定项。

## ZJ-R08 还本付息金额、时间、金融机构与 BIP 匹配

审核要素：核对还本付息申请与 BIP 资金系统贷款信息是否一致。又称「还本付息与 BIP 匹配」。
判定规则：仅当贷款人为外部金融机构时执行本规则，否则不执行。从 B04《贷款信息汇总表》取借款人（可能为简称）、贷款余额（≥ 还本金额）、贷款人（可能为简称），与 B00 还本付息申请表的金额、时间、金融机构比对；要素漏填 / 有误或不符 → 风险。
级别映射：仅贷款人为外部金融机构时，金额 / 时间 / 金融机构任一不符、贷款余额不足还本金额、要素漏填有误 → 风险；均匹配且无漏填 → 通过。贷款人为非外部金融机构 → 原表明确写「否则不执行」，不生成通过项。贷款人性质无法核实时，先核实适用条件，不擅自判风险或通过。
数据锚点：B00 表单取对应字段（还本付息金额 / 时间 / 金融机构）；B04.借款人 / 贷款余额 / 贷款人。依据《珠海交通控股集团有限公司融资管理制度（试行）》。
检索关键词：还本付息、BIP、贷款信息汇总表、贷款余额、还本金额、借款人、贷款人、金融机构、外部金融机构、要素漏填、不匹配、风险。
