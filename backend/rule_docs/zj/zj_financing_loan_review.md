# ZJ 融资借款协审规则

规则版本：V1.0。适用流程：融资借款申请表。适用规则：ZJ-R04, ZJ-R05。
来源：`input/资金/资金审阅规则.xlsx`；完整口径见 `docs/seeds/规则ZJ.md`。本文件为查阅副本，执行规则已内嵌于对应 SOP 节点指导。

## 审阅说明

规则按材料正文识别 B00–B04 来源，文件名仅供辅助。结论级别为风险、关注、通过。原表 D 列明确写「风险·拦截」时按风险判定，H 列原文作为口径依据保留；留空阈值不得自行补造。材料缺失导致不能核实时，记录关注（待补正）并说明未完成实质判定。每条结论保留 rule_id、实际材料与关键字段证据。

## ZJ-R04 融资事项经过集团三会审议

审核要素：核对融资事项是否经集团「三会」审议、决议是否有效。又称「融资决策程序」。
判定规则：先定义「三会」口径（党委会/经营班子会/董事会）；核对 B03 决议类型、日期、文号、议题、审议金额、表决结果、签章七项；缺决议 → 关注（建议补正）；决议晚于申请、事项不符 → 风险·拦截。D5 记风险·拦截、H5 记关注，本库按 D5 记风险，H5 原文作为口径依据保留。
级别映射：缺决议 → 关注；决议晚于申请 / 事项不符 → 风险；决议齐全且有效 → 通过。原表要求核对签章，却未单独定义「签章缺失」的影响；发现缺失时记录关注（待补正）并说明原表未定义该级别，不能声称原表规定为风险。
数据锚点：B03.决议七项核对信息；B00.融资借款申请表申请日期 / 审议金额 / 融资事项。依据《珠海交通控股集团有限公司融资管理制度（试行）》。
检索关键词：融资事项、三会审议、党委会、经营班子会、董事会、决议、文号、表决结果、签章、缺决议、决议晚于申请、事项不符、风险拦截。

## ZJ-R05 融资主体、金额、期限、利率、金融机构符合决议

审核要素：核对融资申请五要素是否落入决议批复范围。又称「融资要素与决议一致」。
判定规则：按 5 个字段逐项拆开比对——主体（可能为简称）、金额（大小写一致，金额 ≤ 决议金额）、期限（≤ 决议期限）、利率（≤ 批复上限）、金融机构（可能为简称）；任一不符 → 风险。
级别映射：五要素任一超出决议/批复或大小写不一致 → 风险；五项均符合 → 通过。
数据锚点：B00.融资主体 / 金额 / 期限 / 利率 / 金融机构；B03.决议对应五项批复。依据《珠海交通控股集团有限公司融资管理制度（试行）》。
检索关键词：融资主体、融资金额、融资期限、利率、金融机构、决议过期、大小写一致、超决议金额、超批复上限、简称、任一不符、风险。
