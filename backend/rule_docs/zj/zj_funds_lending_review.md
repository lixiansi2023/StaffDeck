# ZJ 资金出借协审规则

规则版本：V1.0。适用流程：资金出借审批单。适用规则：ZJ-R06, ZJ-R07。
来源：`input/资金/资金审阅规则.xlsx`；完整口径见 `docs/seeds/规则ZJ.md`。本文件为查阅副本，执行规则已内嵌于对应 SOP 节点指导。

## 审阅说明

规则按材料正文识别 B00–B04 来源，文件名仅供辅助。结论级别为风险、关注、通过。原表 D 列明确写「风险·拦截」时按风险判定，H 列原文作为口径依据保留；留空阈值不得自行补造。材料缺失导致不能核实时，记录关注（待补正）并说明未完成实质判定。每条结论保留 rule_id、实际材料与关键字段证据。

## ZJ-R06 出借决策程序

审核要素：核对资金出借事项是否经集团「三会」审议、决议是否有效。又称「出借决策程序」。
判定规则：先定义「三会」口径（党委会/经营班子会/董事会）；核对 B03 决议类型、日期、文号、议题、审议金额、表决结果、签章七项；缺决议 → 关注（建议补正）；决议晚于申请、事项不符 → 风险·拦截。D7 记风险·拦截、H7 记关注，本库按 D7 记风险，H7 原文作为口径依据保留。
级别映射：缺决议 → 关注；决议晚于申请 / 事项不符 → 风险；决议齐全且有效 → 通过。原表要求核对签章，却未单独定义「签章缺失」的影响；发现缺失时记录关注（待补正）并说明原表未定义该级别，不能声称原表规定为风险。
数据锚点：B03.决议七项核对信息；B00.资金出借审批单申请日期 / 出借金额 / 借款人。依据《珠海交通控股集团有限公司内部借款管理制度（2026年修订）》。
检索关键词：资金出借、出借决策、三会审议、党委会、经营班子会、董事会、决议、文号、表决结果、签章、缺决议、决议晚于申请、风险拦截。

## ZJ-R07 资金出借主体、借款人主体、金额、期限符合决议

审核要素：核对出借审批四要素是否落入决议批复范围。又称「出借要素与决议一致」。
判定规则：按 4 个字段逐项拆开比对——出借主体、借款人主体（可能为简称）、金额（大小写一致，金额 ≤ 决议金额）、期限（≤ 决议期限）；任一不符 → 风险。
级别映射：四要素任一超出决议或大小写不一致 → 风险；四项均符合 → 通过。
数据锚点：B00 表单取对应字段（出借主体 / 借款人主体 / 金额 / 期限）；B03.决议对应四项批复。依据《珠海交通控股集团有限公司内部借款管理制度（2026年修订）》。
检索关键词：出借主体、借款人主体、出借金额、出借期限、决议过期、大小写一致、超决议金额、简称、任一不符、风险。
