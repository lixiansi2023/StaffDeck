规则版本：V1.0。适用流程：融资资金类-资金下拨。适用规则：ZJ-R01, ZJ-R02, ZJ-R03。
来源：`input/资金/资金审阅规则.xlsx`；完整口径见 `docs/seeds/规则ZJ.md`。本文件为查阅副本，执行规则已内嵌于对应 SOP 节点指导。

## 审阅说明

规则按材料正文识别 B00–B04 来源，文件名仅供辅助。结论级别为风险、关注、通过。原表 D 列明确写「风险·拦截」时按风险判定，H 列原文作为口径依据保留；留空阈值不得自行补造。材料缺失导致不能核实时，记录关注（待补正）并说明未完成实质判定。每条结论保留 rule_id、实际材料与关键字段证据。

## ZJ-R01 资金池归集余额

审核要素：核对下拨金额是否超出资金池可用余额，防止超余额下拨、挤占最低备付。又称「归集余额充足性」。
判定规则：读 B01 T-1 日终快照「可用余额」（剔除受限/冻结/质押）与快照日期，比对 B00 下拨金额；可用余额 < 下拨金额＋最低备付额 → 风险·拦截；差额偏小 → 关注·资金部复核；快照过期或缺失 → 关注·待补正转人工。
级别映射：在最低备付额已经确定时，可用余额不足 → 风险；差额落入资金部确定的关注区间、快照过期/缺失 → 关注；余额充足、差额不在关注区间且快照有效 → 通过。最低备付额、关注区间、快照有效天数在原表均为空白占位，未给定时只记录「关注（待补正）」并要求资金部提供，不推断风险或通过。
数据锚点：B00.下拨金额；B01.可用余额 / 快照日期（阈值最低备付额、差额、快照有效天数待资金部给定）。
口径依据：D2 写余额不足「风险·拦截」，H2 写「关注」，本库按 D2 记风险，H2 原文作为口径依据保留。
检索关键词：资金池归集余额、归集余额不足、可用余额、最低备付额、受限冻结质押、T-1 日终、快照过期、风险拦截、资金部复核、待补正转人工。

## ZJ-R02 收、支单位名称

审核要素：核对付款方、收款方单位名称是否与主数据全称一致，防止错付。又称「收支单位名称一致性」。
判定规则：与 B02《集团账户台账/银企主数据》全称逐字比对（含简称、曾用名、错字），区分付款方与收款方两个方向；收款方非合并范围 / 白名单 → 关注，须附审批依据。
级别映射：名称不符（简称/曾用名/错字未澄清）或收款方非白名单且无审批依据 → 关注；两方向全称一致且在合并范围/白名单 → 通过。
数据锚点：B00.收款方名称 / 付款方名称；B02.单位全称 / 简称 / 曾用名 / 合并范围 / 白名单。
检索关键词：收支单位名称、付款方、收款方、全称逐字比对、简称、曾用名、错字、银企主数据、合并范围、白名单、审批依据。

## ZJ-R03 收支单位账号

审核要素：核对收/支账号是否为备案账户、户名与账号是否成对一致。又称「账号一致性」。
判定规则：账号逐位一致 + 户名↔账号成对校验（两条要素共用一条校验逻辑）+ 账户在备案清单内；非备案账户、变更无证明 → 风险·拦截。
级别映射：账号非逐位一致、户名账号不成对、非备案账户或变更无证明 → 风险；三项均符合 → 通过。
数据锚点：B00.收款方账号 / 付款方账号 / 户名；B02.账号备案清单 / 户名↔账号映射 / 账户变更证明。
检索关键词：收支单位账号、账号逐位一致、户名账号成对、备案账户、变更无证明、风险拦截、账号错误。
口径依据：原表 H 列记为「关注」，D 列判定说明为「风险·拦截」，本库按 D 列否决级记「风险」，H 列原文作为口径依据保留。
