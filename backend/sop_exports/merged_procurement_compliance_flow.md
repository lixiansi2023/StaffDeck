# 招采合规一体化全流程（合并）

- **skill_id**: `merged_procurement_compliance_flow`
- **version**: `1.0.0`（库内状态：`active` / `synced`）
- **business_domain**: 采购与供应链合规
- **起点**: `m01`
- **终点**: `m_reject`, `m_handoff`, `m35`, `m30`, `m07`

## 概述

将小明名下的采购合规相关 SOP 合并为一条贯穿流程：合作方入库尽调 → 采购资料收集与附件点验 → 采购方式/资格条件/评分细则合规 → 招标文件文本/保证金/商务合同核心条款/异议澄清弃标校验 → 合同条款风险审查与条款修改建议 → 签约材料齐备性校验 → 协审结论汇总与最终报告。否决类统一终止于否决结论节点，风险/异常类统一转人工。

## 目标

- 按采购合规生命周期顺序完成全链路校验
- 任一分项否决即终止并给出否决结论与整改建议
- 风险/异常统一升级人工，其余汇总为最终合规报告

## 触发意图

采购文件合规审查、招采合规全流程、合并采购合规校验、供应商入库尽调、合同合规审查

## 必要信息

`project_name`、`attachments`、`budget_amount`
