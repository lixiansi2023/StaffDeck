# ZC-F02-R06 商务及合同核心条款

> 规则库 V1.0 ｜ 适用表单：F02 非工程招标采购文件呈批表 ｜ 规则来源：集团《非工程类采购规则》（协审流程）
> 条目 06 / 08 ｜ 对应 SOP 节点：`n6_contract` ｜ 结论槽位：`review_06`

## 1. 审核要素

核对合同模板中履约保证金、付款与质保、验收、违约责任四类核心条款是否权责对等、标准明确。又称「合同核心条款」。

## 2. 通用判定口径

- 结论级别仅可为 **风险 / 关注 / 通过** 三值；规则原文中的「否决」统一记为「风险」，不得使用「预警」「不通过」「异常」等词。
- 附件角色按**内容**识别，文件名只作辅助线索；合同模板通常是 A03 的内附件，不可因单独文件名不含「合同」而判缺失。
- 8 项汇总口径：全部通过 → 建议通过；有风险且可补正 → 建议有条件通过（`condition` 必填）；有风险且不可补正 → 建议不通过；仅有关注 → 建议通过，关注事项跟进。**存在风险项时，综合结论不得为「建议通过」。**
- 本规则为 8 项中的第 06 项，`rule_id = ZC-F02-R06`；本规则只产生 **关注 / 通过**，不产生「风险」。
- **与 R05 的分界**：本规则管**履约保证金**（中标人缴纳，上限为合同金额的 10%）；R05 管**投标保证金**（上限为项目上限价的 2%）。

## 3. 本规则涉及的附件角色

| 角色 | 名称 | 内容识别要点 |
| --- | --- | --- |
| A04 | 合同模板 | 合同体，含甲乙方、标的、付款、验收、履约保证金、违约责任等条款；重点看第 5、6、7、9、12 条 |
| A00 | OA 呈批表 | `form_fields` 含履约保证金比例、合同金额 |

## 4. 判定步骤

1. 从 `source_docs` 取 A04、A00 对应路径，读取两份文件正文（n0 只存路径，未存正文）。
2. 按第 5 节四类问题逐项核对 A04 第 5、6、7、9、12 条；用量阈值时以 A00 的履约保证金比例、合同金额为基准。
3. 命中任一子项即判「关注」；四类均合规判「通过」。
4. `opinion` 逐条点出 A04 条款号与关键比例 / 天数；`evidence` 写明对应条款。

## 5. 四类核对项与级别映射

| 类别 | 命中情形（任一即触发） | level |
| --- | --- | --- |
| ① 履约保证金 | 超过合同金额 10%；或只收现金不接受保函 / 保险；或退还节点与条件不清、设不合理前置条件 | 关注 |
| ② 付款与质保 | 付款节点、比例、验收条件不合理或单方面转嫁风险；无合理依据设超长质保期与回款周期 | 关注 |
| ③ 验收 | 验收标准模糊、无量化指标；验收主体或流程缺失；设与项目无关的验收否决项 | 关注 |
| ④ 违约责任 | 条款权责不对等、仅约束供应商而免除甲方责任；违约金上限不合理 | 关注 |
| 四类均合规 | 未发现上述任何问题 | 通过 |

> 多类同时命中时合并为一条结论，`level` 取「关注」，并在 `opinion` 中逐类列明。

## 6. 数据锚点

- `A04` 第 5、6、7、9、12 条。
- `A00.form_fields`：履约保证金比例、合同金额。
