# ZC-F02-R08 异议澄清弃标流程约定

> 规则库 V1.0 ｜ 适用表单：F02 非工程招标采购文件呈批表 ｜ 规则来源：集团《非工程类采购规则》（协审流程）
> 条目 08 / 08 ｜ 对应 SOP 节点：`n8_objection` ｜ 结论槽位：`review_08`

## 1. 审核要素

核对招标文件中异议（质疑）处理、澄清补遗、中标候选人弃标三类流程是否完备、可执行。又称「异议澄清与弃标处理」。

## 2. 通用判定口径

- 结论级别仅可为 **风险 / 关注 / 通过** 三值；规则原文中的「否决」统一记为「风险」，不得使用「预警」「不通过」「异常」等词。
- 附件角色按**内容**识别，文件名只作辅助线索。
- 8 项汇总口径：全部通过 → 建议通过；有风险且可补正 → 建议有条件通过（`condition` 必填）；有风险且不可补正 → 建议不通过；仅有关注 → 建议通过，关注事项跟进。**存在风险项时，综合结论不得为「建议通过」。**
- 本规则为 8 项中的第 08 项，`rule_id = ZC-F02-R08`；本规则只产生 **关注 / 通过**，不产生「风险」。

## 3. 本规则涉及的附件角色

| 角色 | 名称 | 内容识别要点 |
| --- | --- | --- |
| A03 | 采购（招标）文件全文 | 第七章「异议与澄清」7.1 至 7.5 |

## 4. 判定步骤

1. 从 `source_docs` 取 A03 对应路径，读取招标文件正文（n0 只存路径，未存正文）。
2. 按第 5 节逐项核对第七章 7.1 至 7.5：先确认三类流程的条款是否存在，再确认内容是否明确可执行。
3. 任一缺失或不明确即判「关注」；三类均完备判「通过」。
4. `opinion` 逐条点出 7.x 条款号；`evidence` 写明 A03 第七章具体条款。

## 5. 核对项与级别映射

| 类别 | 完备标准 | 缺失 / 不明确时 level |
| --- | --- | --- |
| ① 异议（质疑）处理 | 载明受理主体、受理时限、答复要求，且未限制供应商正常异议权利 | 关注 |
| ② 澄清补遗 | 明确写明「实质性变更需重新公告并顺延投标截止时间」 | 关注 |
| ③ 弃标处理 | 明确中标候选人弃标后是重新招标还是顺延，处理流程可执行 | 关注 |
| 三类均完备 | 条款齐全且表述明确 | 通过 |

> 多条缺失时合并为一条结论，`level` 取「关注」，并在 `opinion` 中逐类列明。

## 6. 数据锚点
