# ZJ-R07 资金出借主体、借款人主体、金额、期限符合决议

> 规则库 V1.0 ｜ 适用流程：资金出借审批单 ｜ 规则来源：`input/资金/资金审阅规则.xlsx`（集团资金类协审流程规则表）
> 条目 07 / 08 ｜ 本流程内第 02 / 02 项 ｜ 结论槽位：`review_07`

## 1. 审核要素

核对出借审批四要素是否落入决议批复范围。又称「出借要素与决议一致」。

## 2. 通用判定口径

- 结论级别仅可为 **风险 / 关注 / 通过** 三值；规则原文「否决」统一记为「风险」，不得使用「不通过」「异常」等词。
- 数据来源按**内容**识别，文件名只作辅助线索；决议以正文为准。
- 综合结论口径：全部通过 → 建议通过；有风险且可补正 → 建议有条件通过（`condition` 必填）；有风险且不可补正 → 建议不通过；仅有关注 → 建议通过，关注事项跟进。**存在风险项时，综合结论不得为「建议通过」。**
- 本规则 `rule_id = ZJ-R07`；材料齐全时按规则情形判 **风险 / 通过**。必要材料缺失、无法实质判定时按规则库总则记 **关注（待补正）**。

## 3. 本规则涉及的数据来源角色

| 角色 | 名称 | 内容识别要点 |
| --- | --- | --- |
| B00 | 待审表单（费控系统） | 资金出借审批单，含出借主体、借款人主体、金额、期限 |
| B03 | 董事会（三会）决议 / 会议纪要 | 对应四项的批复范围 |

> 四要素须**逐项拆开**比对，不得整体笼统判定。

## 4. 判定步骤

1. 从 `source_docs` 取 B00、B03 对应路径，读取两份材料正文。
2. 按 4 个字段逐项比对：
   - **出借主体**：与决议批复出借主体比对；
   - **借款人主体**：可能为简称，须与决议批复借款人归一后比对；
   - **金额**：大写/小写金额须一致，且金额 ≤ 决议金额；
   - **期限**：出借期限 ≤ 决议期限。
3. 任一字段不符（含超决议范围、大小写金额不一致）→ 风险；四项均符合 → 通过。
4. `opinion` 必须逐字段写出申请值与决议批复值；`evidence` 写明 B03 对应批复条款。

## 5. 级别映射

| 情形 | level |
| --- | --- |
| 出借主体与决议批复不符 | 风险 |
| 借款人主体与决议批复不符 | 风险 |
| 金额大小写不一致，或金额 > 决议金额 | 风险 |
| 期限 > 决议期限 | 风险 |
| 四项均在决议批复范围内 | 通过 |

> 多项同时不符仍只出一条结论，`level` 取「风险」，并在 `opinion` 中逐字段列明。

## 6. 数据锚点

- `B00.出借主体 / 借款人主体 / 金额 / 期限`（表单取对应字段）
- `B03.决议对应四项批复`
