# ZJ-R06 出借决策程序

> 规则库 V1.0 ｜ 适用流程：资金出借审批单 ｜ 规则来源：`input/资金/资金审阅规则.xlsx`（集团资金类协审流程规则表）
> 条目 06 / 08 ｜ 本流程内第 01 / 02 项 ｜ 结论槽位：`review_06`

## 1. 审核要素

核对资金出借事项是否经集团「三会」审议、决议是否有效。又称「出借决策程序」。

## 2. 通用判定口径

- 结论级别仅可为 **风险 / 关注 / 通过** 三值；规则原文「否决」「拦截」统一记为「风险」，不得使用「不通过」「异常」等词。
- 数据来源按**内容**识别，文件名只作辅助线索；决议以正文为准。
- 综合结论口径：全部通过 → 建议通过；有风险且可补正 → 建议有条件通过（`condition` 必填）；有风险且不可补正 → 建议不通过；仅有关注 → 建议通过，关注事项跟进。**存在风险项时，综合结论不得为「建议通过」。**
- 本规则 `rule_id = ZJ-R06`；只产生 **风险 / 关注 / 通过**。
- **与 ZJ-R04 的分界**：同为「三会决议」核对，本规则用于**资金出借审批单**（依据《内部借款管理制度（2026年修订）》）；ZJ-R04 用于**融资借款申请表**（依据《融资管理制度（试行）》）。

## 3. 本规则涉及的数据来源角色

| 角色 | 名称 | 内容识别要点 |
| --- | --- | --- |
| B00 | 待审表单（费控系统） | 资金出借审批单，含申请日期、出借金额、借款人 |
| B03 | 董事会（三会）决议 / 会议纪要 | 决议类型、日期、文号、议题、审议金额、表决结果、签章 |

> 「三会」口径须先定义（党委会 / 经营班子会 / 董事会），再按口径核对决议类型。

## 4. 判定步骤

1. 从 `source_docs` 取 B00、B03 对应路径，读取两份材料正文。
2. 先定义「三会」口径（党委会 / 经营班子会 / 董事会）。
3. 核对 B03 决议七项信息：类型、日期、文号、议题、审议金额、表决结果、签章是否齐全有效。
4. 缺决议 → 关注（建议补正）；决议日期晚于出借申请日期、或决议事项与本次出借事项不符 → 风险·拦截；决议齐全有效 → 通过。签章须核对，但原表未单独规定缺签章的结论级别；缺签章时记关注（待补正）并说明原表未定义该级别。
5. `opinion` 必须写出决议文号、日期、审议金额与申请日期的先后关系；`evidence` 写明 B03 对应条款/字段。

## 5. 级别映射

| 情形 | level |
| --- | --- |
| 缺决议（建议补正） | 关注 |
| 决议日期晚于出借申请 | 风险 |
| 决议事项与出借事项不符 | 风险 |
| 决议签章缺失（原表未明确影响级别） | 关注（待补正，执行兜底口径） |
| 决议齐全、日期合规、事项相符、签章完整 | 通过 |
