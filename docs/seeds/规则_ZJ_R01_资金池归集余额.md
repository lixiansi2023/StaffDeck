# ZJ-R01 资金池归集余额

> 规则库 V1.0 ｜ 适用流程：融资资金类-资金下拨 ｜ 规则来源：`input/资金/资金审阅规则.xlsx`（集团资金类协审流程规则表）
> 条目 01 / 08 ｜ 本流程内第 01 / 03 项 ｜ 结论槽位：`review_01`

## 1. 审核要素

核对下拨金额是否超出资金池可用余额，防止超余额下拨、挤占最低备付。又称「归集余额充足性」。

## 2. 通用判定口径

- 结论级别仅可为 **风险 / 关注 / 通过** 三值；规则原文中的「否决」「拦截」统一记为「风险」，不得使用「不通过」「异常」等词。原表 D2 写「余额不足→风险·拦截」、H2 写「关注」，本库按 D2 记「风险」，H2 原文作为口径依据保留。
- 数据来源按**内容**识别，文件名只作辅助线索；不得因文件名不含「余额表」就判定缺失。
- 综合结论口径：全部通过 → 建议通过；有风险且可补正 → 建议有条件通过（`condition` 必填）；有风险且不可补正 → 建议不通过；仅有关注 → 建议通过，关注事项跟进。**存在风险项时，综合结论不得为「建议通过」。**
- 本规则 `rule_id = ZJ-R01`，适用于「融资资金类-资金下拨」流程，只产生 **风险 / 关注 / 通过**。

## 3. 本规则涉及的数据来源角色

| 角色 | 名称 | 内容识别要点 |
| --- | --- | --- |
| B00 | 待审表单（费控系统） | 资金下拨表单，含下拨金额；流程为子公司经办-财务经理-公司负责人-集团资金部资金管理岗，无需集团高层领导审批 |
| B01 | 资金池归集余额表 | 资金系统 T-1 日终快照，含「可用余额」（已剔除受限/冻结/质押）与快照日期 |

> 阈值（最低备付额、差额关注区间、快照有效天数）在规则原表中为占位符，评审前须由资金部给定；阈值未给定时不得推断风险或通过，应记「关注（待补正）」。

## 4. 判定步骤

1. 从 `source_docs` 取 B00、B01 对应路径，读取两份材料正文。
2. 读 B01「可用余额」（确认已剔除受限/冻结/质押）与快照日期；读 B00 下拨金额。
3. 校验快照时效：快照超约定天数或缺失 → 关注（待补正转人工），不据此直接下风险结论。
4. 比对 `可用余额` 与 `下拨金额＋最低备付额`：
   - 可用余额 < 下拨金额＋最低备付额 → 风险·拦截；
   - 可用余额 ≥ 下拨金额＋最低备付额，但安全垫偏薄（差额落入关注区间）→ 关注·资金部复核；
   - 余额充足且快照有效 → 通过。
5. `opinion` 必须写出可用余额、下拨金额、最低备付额与差额的具体数值；`evidence` 写明 B01 快照日期与 B00 对应字段。

## 5. 级别映射

| 情形 | level |
| --- | --- |
| 可用余额 < 下拨金额＋最低备付额（拦截） | 风险 |
| 差额偏薄，需资金部复核 | 关注 |
| 快照超约定天数或缺失（待补正转人工） | 关注 |
| 余额充足，且快照在有效期内 | 通过 |

> 多项同时存在时取最高级别（风险），并在 `opinion` 中并列说明。

## 6. 数据锚点

- `B00.下拨金额`
- `B01.可用余额`（已剔除受限/冻结/质押）
- `B01.快照日期`
- 阈值：最低备付额、差额关注区间、快照有效天数（规则原表为占位符，待资金部给定）
