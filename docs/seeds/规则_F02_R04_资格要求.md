# ZC-F02-R04 资格要求

> 规则库 V1.0 ｜ 适用表单：F02 非工程招标采购文件呈批表 ｜ 规则来源：集团《非工程类采购规则》（协审流程）
> 条目 04 / 08 ｜ 对应 SOP 节点：`n4_qualification` ｜ 结论槽位：`review_04`

## 1. 审核要素

逐条比对资格条件与采购需求的关联性，排查排斥或变相排斥潜在投标人的限制性条款。又称「资格条件关联性」。

## 2. 通用判定口径

- 结论级别仅可为 **风险 / 关注 / 通过** 三值；规则原文中的「否决」统一记为「风险」，不得使用「预警」「不通过」「异常」等词。
- 附件角色按**内容**识别，文件名只作辅助线索。
- 8 项汇总口径：全部通过 → 建议通过；有风险且可补正 → 建议有条件通过（`condition` 必填）；有风险且不可补正 → 建议不通过；仅有关注 → 建议通过，关注事项跟进。**存在风险项时，综合结论不得为「建议通过」。**
- 本规则为 8 项中的第 04 项，`rule_id = ZC-F02-R04`。
- **与 R07 的分界**：同为「品牌 / 专利 / 产地 / 业绩 / 地域」类问题，出现在**资格条件**（第三章）按本规则记 **风险**；出现在**评分细则**（第五章）按 R07 记 **关注**。

## 4. 判定步骤

1. 从 `source_docs` 取 A03、A01 对应路径，读取两份文件正文（n0 只存路径，未存正文）。
2. 以 A01 采购需求清单为基准，逐条核对 A03 第三章 3.1 至 3.6 的资格条件。
3. 出现下表任一情形即命中；命中多条时合并为一条结论，`level` 取「风险」，`opinion` 逐条点出违规条款号。
4. 均以采购需求为基准、无下列限制时判「通过」；`evidence` 写明 A03 第三章具体条款。

## 5. 级别映射与命中情形

| 命中情形（任一即触发） | level |
| --- | --- |
| 指定特定品牌、专利或产地 | 风险（否决） |
| 指定特定客户或特定项目业绩 | 风险（否决） |
| 资质等级超出项目实际规模 | 风险（否决） |
| 设置地域性限制条件 | 风险（否决） |
| 资格条件均与采购需求相关，且无上述限制 | 通过 |

> 本项目为非工程货物采购，采购方案已明确不指定品牌，应据此重点核对 A03 第 3.2、3.4 条。
