# ZJ-R05 融资主体、金额、期限、利率、金融机构符合决议

> 规则库 V1.0 ｜ 适用流程：融资借款申请表 ｜ 规则来源：`input/资金/资金审阅规则.xlsx`（集团资金类协审流程规则表）
> 条目 05 / 08 ｜ 本流程内第 02 / 02 项 ｜ 结论槽位：`review_05`

## 1. 审核要素

核对融资申请五要素是否落入决议批复范围。又称「融资要素与决议一致」。

## 2. 通用判定口径

- 结论级别仅可为 **风险 / 关注 / 通过** 三值；规则原文「否决」统一记为「风险」，不得使用「不通过」「异常」等词。
- 数据来源按**内容**识别，文件名只作辅助线索；决议以正文为准。
- 综合结论口径：全部通过 → 建议通过；有风险且可补正 → 建议有条件通过（`condition` 必填）；有风险且不可补正 → 建议不通过；仅有关注 → 建议通过，关注事项跟进。**存在风险项时，综合结论不得为「建议通过」。**
- 本规则 `rule_id = ZJ-R05`；材料齐全时按规则情形判 **风险 / 通过**。必要材料缺失、无法实质判定时按规则库总则记 **关注（待补正）**。

## 3. 本规则涉及的数据来源角色

| 角色 | 名称 | 内容识别要点 |
| --- | --- | --- |
| B00 | 待审表单（费控系统） | 融资借款申请表，含融资主体、金额、期限、利率、金融机构 |
| B03 | 董事会（三会）决议 / 会议纪要 | 对应五项的批复范围 |

> 五要素须**逐项拆开**比对，不得整体笼统判定。

## 4. 判定步骤

1. 从 `source_docs` 取 B00、B03 对应路径，读取两份材料正文。
2. 按 5 个字段逐项比对：
   - **主体**：可能为简称，须与决议批复主体归一后比对；
   - **金额**：大写/小写金额须一致，且金额 ≤ 决议金额；
   - **期限**：申请期限 ≤ 决议期限；
   - **利率**：≤ 批复利率上限；
   - **金融机构**：可能为简称，须与决议批复机构归一后比对。
3. 任一字段不符（含超决议/批复范围、大小写金额不一致）→ 风险；五项均符合 → 通过。
4. `opinion` 必须逐字段写出申请值与决议批复值；`evidence` 写明 B03 对应批复条款。

## 5. 级别映射

| 情形 | level |
| --- | --- |
| 主体与决议批复不符 | 风险 |
| 金额大小写不一致，或金额 > 决议金额 | 风险 |
| 期限 > 决议期限 | 风险 |
| 利率 > 批复上限 | 风险 |
| 金融机构与决议批复不符 | 风险 |
| 五项均在决议/批复范围内 | 通过 |

> 多项同时不符仍只出一条结论，`level` 取「风险」，并在 `opinion` 中逐字段列明。

## 6. 数据锚点

- `B03.决议对应五项批复`
