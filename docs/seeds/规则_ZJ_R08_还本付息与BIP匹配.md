# ZJ-R08 还本付息金额、时间、金融机构与 BIP 匹配

> 规则库 V1.0 ｜ 适用流程：还本付息申请表 ｜ 规则来源：`input/资金/资金审阅规则.xlsx`（集团资金类协审流程规则表）
> 条目 08 / 08 ｜ 本流程内第 01 / 01 项 ｜ 结论槽位：`review_08`

## 1. 审核要素

核对还本付息申请与 BIP 资金系统贷款信息是否一致。又称「还本付息与 BIP 匹配」。

## 2. 通用判定口径

- 结论级别仅可为 **风险 / 关注 / 通过** 三值；规则原文「否决」统一记为「风险」，不得使用「不通过」「异常」等词。
- 数据来源按**内容**识别，文件名只作辅助线索。
- 综合结论口径：全部通过 → 建议通过；有风险且可补正 → 建议有条件通过（`condition` 必填）；有风险且不可补正 → 建议不通过；仅有关注 → 建议通过，关注事项跟进。**存在风险项时，综合结论不得为「建议通过」。**
- 本规则 `rule_id = ZJ-R08`；触发且材料齐全时按规则情形判 **风险 / 通过**。必要材料缺失、无法实质判定时按规则库总则记 **关注（待补正）**。
- **适用前提**：仅当贷款人为**外部金融机构**时执行本规则；否则按原表「不执行」，不生成判定项，也不计入通过项。贷款人性质无法核实时先核实适用条件。

## 3. 本规则涉及的数据来源角色

| 角色 | 名称 | 内容识别要点 |
| --- | --- | --- |
| B00 | 待审表单（费控系统） | 还本付息申请表，含还本付息金额、时间、金融机构 |
| B04 | 贷款信息汇总表（BIP 资金系统） | 借款人、贷款余额、贷款人、还本付息节点 |

> 借款人、贷款人可能为简称，须归一后比对；贷款余额须能覆盖还本金额。

## 4. 判定步骤

1. 从 `source_docs` 取 B00、B04 对应路径，读取两份材料正文。
2. 先判断贷款人是否为外部金融机构：否 → 本规则不执行，记录未触发原因，不生成 `review_08`；是 → 继续下步。
3. 从 B04 取借款人（可能为简称）、贷款余额、贷款人（可能为简称），与 B00 还本付息申请表比对：
   - **借款人**归一后是否一致；
   - **贷款余额** ≥ 本次还本金额；
   - **贷款人 / 金融机构**归一后是否一致；
   - **还本付息时间**与 B04 还本付息节点是否吻合；
   - 上述要素是否漏填 / 有误。
4. 任一要素不符、贷款余额不足还本金额、或要素漏填有误 → 风险；均匹配且无漏填 → 通过。
5. `opinion` 必须写出申请值、BIP 值与贷款余额；`evidence` 写明 B04 对应字段。

## 5. 级别映射

| 情形 | level |
| --- | --- |
| 金额 / 时间 / 金融机构任一与 BIP 不符 | 风险 |
| 贷款余额 < 还本金额 | 风险 |
| 要素漏填 / 有误 | 风险 |
| 均匹配且无漏填 | 通过 |
| 贷款人为非外部金融机构（本规则不适用） | 不执行；不生成 item，不计入统计 |
