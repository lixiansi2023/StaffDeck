# ZJ-R03 收支单位账号

> 规则库 V1.0 ｜ 适用流程：融资资金类-资金下拨 ｜ 规则来源：`input/资金/资金审阅规则.xlsx`（集团资金类协审流程规则表）
> 条目 03 / 08 ｜ 本流程内第 03 / 03 项 ｜ 结论槽位：`review_03`

## 1. 审核要素

核对收/支账号是否为备案账户、户名与账号是否成对一致。又称「账号一致性」。

## 2. 通用判定口径

- 结论级别仅可为 **风险 / 关注 / 通过** 三值；规则原文「否决」「拦截」统一记为「风险」，不得使用「不通过」「异常」等词。
- 数据来源按**内容**识别，文件名只作辅助线索。
- 综合结论口径：全部通过 → 建议通过；有风险且可补正 → 建议有条件通过（`condition` 必填）；有风险且不可补正 → 建议不通过；仅有关注 → 建议通过，关注事项跟进。**存在风险项时，综合结论不得为「建议通过」。**
- 本规则 `rule_id = ZJ-R03`；材料齐全时按规则情形判 **风险 / 通过**。必要材料缺失、无法实质判定时按规则库总则记 **关注（待补正）**。
- **级别口径依据**：原表「判定结论的影响」列记为「关注」，「判定具体说明」写「非备案账户/变更无证明 → 风险·拦截」。本库按判定说明的否决级记「风险」，H 列原文作为口径依据保留。

## 3. 本规则涉及的数据来源角色

| 角色 | 名称 | 内容识别要点 |
| --- | --- | --- |
| B00 | 待审表单（费控系统） | 资金下拨表单，含收款方账号、付款方账号、户名 |
| B02 | 账户台账 / 银企主数据 | 账号备案清单、户名↔账号映射、账户变更证明 |

> 「账号逐位一致」与「户名↔账号成对校验」两条要素应共用同一条校验逻辑，不得分拆为两套口径。

## 4. 判定步骤

1. 从 `source_docs` 取 B00、B02 对应路径，读取两份材料正文。
2. **逐位比对** B00 收款方/付款方账号与 B02 备案账号，任一位不符即命中。
3. **成对校验** 户名↔账号映射，确认户名与账号属于同一主体。
4. **备案校验** 确认账户在 B02 备案清单内；账户变更须附变更证明。
5. 三项均符合 → 通过；账号非逐位一致、户名账号不成对、非备案账户或变更无证明 → 风险·拦截。
6. `opinion` 必须写出账号比对结果与备案状态；`evidence` 写明 B02 备案清单对应条目。

## 5. 级别映射

| 情形 | level |
| --- | --- |
| 账号非逐位一致 | 风险 |
| 户名与账号不成对 | 风险 |
| 非备案账户，或账户变更无证明 | 风险 |
| 账号逐位一致、户名账号成对、且在备案清单内 | 通过 |

## 6. 数据锚点

- `B00.收款方账号` / `B00.付款方账号` / `B00.户名`
- `B02.账号备案清单` / `户名↔账号映射` / `账户变更证明`

## 7. 检索关键词
