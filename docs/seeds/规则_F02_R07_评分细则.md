> 规则库 V1.0 ｜ 适用表单：F02 非工程招标采购文件呈批表 ｜ 规则来源：集团《非工程类采购规则》（协审流程）
> 条目 07 / 08 ｜ 对应 SOP 节点：`n7_scoring` ｜ 结论槽位：`review_07`

## 1. 审核要素

核对评分细则是否设置倾向性或歧视性评分项，避免以加分方式变相指定品牌、业绩或地域。又称「评分标准」。

## 2. 通用判定口径

- 结论级别仅可为 **风险 / 关注 / 通过** 三值；规则原文中的「否决」统一记为「风险」，不得使用「预警」「不通过」「异常」等词。
- 附件角色按**内容**识别，文件名只作辅助线索。
- 8 项汇总口径：全部通过 → 建议通过；有风险且可补正 → 建议有条件通过（`condition` 必填）；有风险且不可补正 → 建议不通过；仅有关注 → 建议通过，关注事项跟进。**存在风险项时，综合结论不得为「建议通过」。**
- 本规则为 8 项中的第 07 项，`rule_id = ZC-F02-R07`；本规则只产生 **关注 / 通过**，不产生「风险」。
- **与 R04 的分界**：同为「品牌 / 专利 / 产地 / 业绩 / 地域」类问题，出现在**评分细则**（第五章）按本规则记 **关注**；出现在**资格条件**（第三章）按 R04 记 **风险**（否决）。

## 4. 判定步骤

1. 从 `source_docs` 取 A03 对应路径，读取招标文件正文（n0 只存路径，未存正文）。
2. 逐项核对第五章 5.1 至 5.5 的评分项与加分条件，对照第 5 节四类命中情形。
3. 命中任一即判「关注」；四类均未发现判「通过」。
4. `opinion` 逐条点出 5.x 条款号；`evidence` 写明 A03 第五章具体条款。

## 5. 命中情形与级别映射

| 命中情形（任一即触发） | level |
| --- | --- |
| 出现特定单一品牌名、专利或特定产地加分 | 关注 |
| 业绩要求指定特定客户或项目，或超出项目规模 | 关注 |
| 技术参数要求高于行业通用标准 | 关注 |
| 设置地域性限制条件 | 关注 |
| 四类问题均未发现 | 通过 |

> 关注项仍可推进流程，但须在评审意见中列明并跟进补正。
