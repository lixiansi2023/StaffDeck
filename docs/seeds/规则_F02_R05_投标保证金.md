# ZC-F02-R05 投标保证金

> 规则库 V1.0 ｜ 适用表单：F02 非工程招标采购文件呈批表 ｜ 规则来源：集团《非工程类采购规则》（协审流程）
> 条目 05 / 08 ｜ 对应 SOP 节点：`n5_bid_bond` ｜ 结论槽位：`review_05`

## 1. 审核要素

核对投标保证金金额是否合规、递交方式是否保留合法替代形式。又称「保证金合规」。

## 2. 通用判定口径

- 结论级别仅可为 **风险 / 关注 / 通过** 三值；规则原文中的「否决」统一记为「风险」，不得使用「预警」「不通过」「异常」等词。
- 附件角色按**内容**识别，文件名只作辅助线索。
- 8 项汇总口径：全部通过 → 建议通过；有风险且可补正 → 建议有条件通过（`condition` 必填）；有风险且不可补正 → 建议不通过；仅有关注 → 建议通过，关注事项跟进。**存在风险项时，综合结论不得为「建议通过」。**
- 本规则为 8 项中的第 05 项，`rule_id = ZC-F02-R05`；本规则只产生 **关注 / 通过**，不产生「风险」。
- **与 R06 的分界**：本规则管**投标保证金**（投标人缴纳，上限为项目上限价的 2%）；R06 管**履约保证金**（中标人缴纳，上限为合同金额的 10%）。

## 4. 判定步骤

1. 从 `source_docs` 取 A00、A03 对应路径，读取两份文件正文（n0 只存路径，未存正文）。
2. 计算合规阈值：`上限价 × 2%`，与招标文件载明的保证金金额比较。
3. 检查递交方式是否排除保函、保险保单等合法替代形式；仅接受现金转账即属异常。
4. `opinion` 必须写出保证金金额、上限价、`2%` 的计算结果与递交方式；`evidence` 写明 A03 第四章与 A00 对应字段。

## 5. 级别映射

| 情形（任一即触发） | level |
| --- | --- |
| 未设置投标保证金 | 关注 |
| 保证金金额超过上限价的 2% | 关注 |
| 只接受现金，不接受保函 / 保险保单 | 关注 |
| 金额未超 2%，且接受保函或保险等合法替代形式 | 通过 |

> 多条异常同时存在时合并为一条结论，`level` 取「关注」，并在 `opinion` 中逐项说明。
